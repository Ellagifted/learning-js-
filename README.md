# Learning JS

A small JavaScript practice project for learning core programming concepts through beginner-friendly examples.

## Overview

This project contains a collection of JavaScript exercises that demonstrate:

- Variables and data types
- Arithmetic and string operations
- Conditional statements
- Arrays and array methods
- Loops (`for`, `while`)
- Functions and arrow functions
- Basic logic and decision-making

The script logs results to the browser console so you can see how each concept behaves in real time.

## Project files

- `index.html` - basic page structure
- `style.css` - simple styling for the page
- `learn.js` - JavaScript exercises and examples

## What is covered

The examples include:

- Student score and grading logic
- Weather conditions based on temperature
- Concatenating strings and numbers
- Array manipulation (`push`, `pop`, `unshift`, `shift`, `includes`)
- Looping through arrays and numbers
- Break and continue statements
- `map()` operations for transforming arrays
- Arrow function examples and calculations

## How to run it

1. Open the project folder in your browser or code editor.
2. Open `index.html` in a browser.
3. Open the browser developer console (`F12` or right-click > Inspect).
4. View the output generated by `learn.js`.

You can also serve it locally with a simple web server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Learning purpose

This project is designed for practicing JavaScript fundamentals in a simple and readable way. It is perfect for beginners who want to understand how JavaScript works before moving on to larger applications.
